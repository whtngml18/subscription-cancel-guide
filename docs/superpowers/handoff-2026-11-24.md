## 구조 메모
- 공통 조각 `fragments/layout.html`: pageHead(title, description, path) / noindexHead / adminHead / siteHeader / adminHeader / siteFooter. (head·header·footer라는 조각 이름은 같은 태그까지 선택돼서 쓰지 않음)
- `fragments/phone.html`, `fragments/subscription-fields.html`, `app.base-url`(APP_BASE_URL). manifest는 `manifest.json`.
- 제보는 IP당 1시간 10번(SubmitRateLimiter), 2MB 초과 업로드는 UploadLimitAdvice가 폼으로 되돌림.
- AI: 학교 factchat API Gateway(OpenAI 호환) `https://factchat-cloud.mindlogic.ai/v1/gateway`, 경로 끝에 `/` 필요(`/chat/completions/`). 월 크레딧 한도 있음. 코드는 `ai/` 패키지(StepParser, FactchatStepParser, AiStepsJson, AiPreviewRateLimiter).
- 키는 Windows 사용자 환경변수 FACTCHAT_API_KEY. 앱 실행 시 `powershell [Environment]::GetEnvironmentVariable('FACTCHAT_API_KEY','User')`로 읽어 넘김. **값은 절대 출력하지 않음.**
